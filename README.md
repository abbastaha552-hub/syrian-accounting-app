# 💼 حسابي — تطبيق المحاسبة بالليرة السورية

تطبيق محاسبة متكامل مبني بـ React، مصمم خصيصاً للسوق السورية.

## المميزات

- 📊 **لوحة التحكم** — نظرة عامة على الأداء المالي مع رسوم بيانية
- 📋 **المعاملات** — تسجيل وإدارة الإيرادات والمصروفات
- 🧾 **الفواتير** — إنشاء فواتير احترافية مع إمكانية الطباعة
- 👥 **العملاء** — قاعدة بيانات كاملة للعملاء والذمم المدينة
- 📈 **التقارير** — قائمة الدخل وملخص الأعمال
- 🇸🇾 **الليرة السورية (ل.س)** — جميع المبالغ بالليرة السورية
- 🌙 **الوضع الليلي** — واجهة داكنة مريحة للعين

## تشغيل التطبيق

```bash
npm install
npm run dev
```

ثم افتح المتصفح على: http://localhost:5173

## البناء للإنتاج

```bash
npm run build
```

## التقنيات المستخدمة

- React 18
- Vite
- خط Tajawal (Google Fonts)
